# Wuertbuerg — приложение на iPhone

## Как установить (один раз, ~5 минут, с компьютера)
1. Зайди на github.com под своим аккаунтом (kovaldmitry) → New repository → имя `wuertbuerg` → Public → Create.
2. На странице репозитория: «uploading an existing file» → перетащи ВСЁ содержимое этой папки (index.html, sw.js, manifest.json, иконки и папку pics) → Commit changes.
3. Settings → Pages → Source: «Deploy from a branch» → Branch: main, папка / (root) → Save.
4. Через 1–2 минуты сайт будет по адресу: https://kovaldmitry.github.io/wuertbuerg/

## На iPhone
1. Открой этот адрес в Safari (именно Safari).
2. Кнопка «Поделиться» → «На экран Домой» → «Добавить».
3. Запускай с иконки замка: откроется на весь экран, без адресной строки, и работает без интернета.

## Обновления
Когда Claude пришлёт новую версию — загрузи новые файлы в тот же репозиторий поверх старых.
Прогресс хранится в самом приложении на телефоне и при обновлении не пропадает.
Не удаляй иконку с экрана «Домой» — вместе с ней iOS удаляет и прогресс.
